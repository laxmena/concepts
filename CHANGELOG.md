# Changelog

## Unreleased

- Spaced repetition page (new area "Learning and memory"): a toy forgetting model (recall 0.9^(t/S), each review multiplies stability by 1 + 6(1 − recall)), cram against fixed gaps against just-in-time reviews, and a live break where one fixed gap fits a slippery fact badly. Tests are checked against an independent Python implementation. Sources checked: Cepeda and others (2006) and the Anki manual (default desired retention 90%).
- Quantization page: absmax rounding of a made-up row of 64 weights to 2 to 8 bits, one scale for the row or per 32 or per 8 weights, model size for 7 billion weights, and a live outlier break (one large weight zeroes most of a row that shares its scale; smaller groups contain it and cost more bits). Tests are checked against an independent Python implementation. New `.cards.rl.q` phone layout.
- Tokenization page: byte-pair encoding trained live in the browser on a small English corpus (and an English plus Tamil one), with a Tamil break: UTF-8 bytes, merge budget and real tiktoken 0.14.0 counts for the same greeting (cl100k 19 tokens, o200k 5, English 2). Tests check hand-worked merges and an independent Python implementation. New `.toks`/`.tok` chip styles.
- KV cache page: tokens run per step and in total with and without a cache (n versus n(n+1)/2), cache bytes per token for a Llama 3 8B-shaped model, and a live break where many people at once fill a GPU, with 8 versus 32 key/value heads. Tests use hand-worked values.
- Atom feed at `/feed.xml`, built from `concepts.json` by `npm run feed` (`shared/feed.js`). A test fails if `feed.xml` is out of date, so run the script after adding a page. The home page links it in the head and the footer.
- "New" tag on the home list for 30 days after a page's `added` date in `concepts.json` (`new-concept.sh` sets it). Attention, RL, RLHF and LoRA carry it for now.
- Home footer: "Notes I keep for myself, added as I learn", a link to GitHub issues for mistakes, and the source link.
- Two GA4 events, sent only after consent: `widget_used` (first control touched, once per widget per load; `concept`, `widget` = main or breaks) and `answer_opened` (`concept`, `question` = 1 to 3). Register `concept`, `widget` and `question` as custom dimensions in GA to see them in reports.
- Service worker is now network first with revalidation (`concepts-v2`). Before, it served the cached copy first, so a deploy needed two reloads and GitHub Pages' 10 minute cache made it worse. Offline still works from the cache.
- LoRA page: a toy update built from known orthogonal vectors so the best rank-r approximation is exact (checked against the Eckart–Young sum of squares), real-layer parameter counts, and a spread-out update as the break.
- Google Analytics 4 (page views only), loaded by `shared/analytics.js` after the reader clicks Allow on a small banner. Off on localhost, Google signals and ad personalisation off, a footer link changes the choice. The measurement ID is shared with the author's other site; filter by hostname in GA.
- RLHF page: the KL-penalised optimum over five replies (p ∝ ref · e^(r/β)), checked against Python numbers and a brute-force search, plus a live over-optimisation break where the reward model score keeps rising while the quality people would give peaks and falls. New helpers in CSS: `.cards.rl` (a wide card beside two stacked ones), `.controls.one`.
- Reinforcement learning page: a 3 by 5 grid world with Q-learning, a live reward-hacking break (a coin that pays on every visit, solved exactly by value iteration, flips near +0.16 at γ 0.9). Tests check the closed form γ^(d−1), a hand-worked update, and Python value-iteration numbers. Attention: the sentence toggle now has words and a visible label (`.segmented.wide`).
- Attention page (area "Machine learning"): one word attends to the others, two sentences, a divisor slider, and the n by n cost live. Tests use values computed in Python. New `.wrows` rows in the stylesheet.
- Type scale: five sizes as tokens (13, 15, 17, 22, 36px), hero bullets smaller than the body, mono for numbers only, line height 1.65 for prose, tighter section spacing, three cards side by side instead of an orphan. The title now fits two lines and the hero column is about 200px shorter.
- Home page: simpler and quieter. Titles only, areas side by side, a series (the evals) opens with "Start here" and numbers the rest in reading order. Areas renamed to "Evals" and "Search and ranking". Intro no longer ties every page to the newsletter; AGENTS.md and STYLE.md now describe the wider scope (computer science and engineering, senior and principal engineers).
- Evals series, twelve pages, each with a live "where it breaks" widget, tests against independently computed values, and sources opened and checked: the map of evals; error bars and sample size (Miller 2024); exact match and F1 (SQuAD); precision, recall and reciprocal rank; pass@k (Chen et al. 2021); LLM as judge (Zheng et al. 2023, real counts of 80 questions); pairwise votes, Elo and Bradley-Terry (Chiang et al. 2024); human agreement and kappa; RAG evals (RAGAS); agent evals and pass^k (tau-bench); online evals and peeking; contamination and Goodhart (GSM1k).
- Shared: `shared/stats.js` (normal quantile, Wilson interval, seeded random numbers), `radios` helper, tile grids, `[hidden]` rule, phone helper classes. `scripts/e2e/evals.mjs` smoke-tests every page of the series; `fit.mjs` ignores cards in a closed `<details>`.
- Manifest order: the map first, then a reading order. Eval pages link to the map in the header.
- Every page has a one-line "what it is" under the title (`.what`), also in the template and STYLE.md.
- White theme only: white page, faintly warm cards, brown ink. Dark mode removed on purpose.
- Warmer theme: cream page, brown ink, softer orange and blue, warm brown dark mode, rounded cards, inputs and pill buttons, a darker focus ring (`--focus`). Roles are unchanged (orange explains, blue compares). AGENTS.md and STYLE.md updated.
- BM25 page, friendlier: cards show the real text with matching words highlighted (phones keep the word squares), cards are ranked best first with a #1 to #4 tag, search box and the two toggles share one row so the cards still fit 1280x720, "Try your own documents" replaces "Change the documents". Empty "Used in" section is hidden. Tests for `splitText` and `rankOrder`.
- Page: bi-encoder vs cross-encoder. Side-by-side diagram, N slider (10 to 1,000,000), "Run a search" simulation with running totals, log-scale time bars, retrieve-and-rerank demo. No model runs; unit costs are made up and labelled. Tests worked by hand, including 10,000 sentences = 49,995,000 pairs (Sentence-BERT paper: about 50 million).
- Page: nDCG@k. Ten draggable results with grades, live DCG / best possible / nDCG, a k slider with a cut-off line, three small pictures, and the incomplete-judgments demo. Tests worked by hand, including the textbook example (nDCG6 = 0.961).
- Shared helpers: `sortableList`, `segmented`, `meter`.
- Shared layer: stylesheet, page template, helpers (DOM, slider, reveal, bar charts, editable list), offline service worker.
- BM25 page, picture first: a 2x2 grid of cards (word squares, score bar split by search word, one plain sentence each), optional plain-count bar, index lookup view, "never read" tag. Fits one screen on laptop and phone. Tables and formula are folded away. Tests checked against bm25s 0.3.16.
- "What just happened" is three small pictures (coins for rarity, a bar cut into shrinking pieces for repeats, one match in a short and a long text); the last two follow the k1 and b sliders.
- STYLE.md (colour roles, type, layout, picture vocabulary, writing, accessibility, checks). Browser checks in `scripts/e2e/` (`npm run e2e`). Blue now marks the comparison in the length picture; word squares darker.
- Home page lists titles only.
- Home page built from `concepts.json`; `new-concept.sh`; CI with tests, link check and Pages deploy.
